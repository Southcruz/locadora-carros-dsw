# Rota Prime

Site estático de uma locadora de veículos fictícia, desenvolvido para um projeto acadêmico de desenvolvimento web.

## Estrutura

```text
.
├── index.html              # Página inicial
├── pages/                  # Páginas internas
│   ├── catalogo.html
│   ├── reserva.html
│   ├── servicos.html
│   └── sobre.html
├── assets/
│   ├── css/style.css       # Estilos globais
│   └── images/             # Imagens locais do projeto
└── README.md
```

## Como executar

Abra o arquivo `index.html` no navegador. Como o projeto é estático, não há dependências ou servidor obrigatório.

As imagens da frota são carregadas de URLs externas do Unsplash.
